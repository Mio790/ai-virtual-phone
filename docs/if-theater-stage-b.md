## 修正与数据语义

- 普通 Send 通过 applyIFReply 更新当前 saveId，不创建分支或新存档。每轮只调用一次流式请求，无自动重试、回退、总结、标题或 DM 请求。
- 菜单 Re-roll 对所选助手消息之前的用户消息重新请求；不包含旧回复及旧后续。原存档及后续保留，新版本另存。版本族记录 saveIds/index；左右箭头、版本计数和分支下拉均选中该版本自己的历史。连续续写只更新选中版本的分支。
- Edit、Delete、Backtrack、主动另存才派生分支。Delete 的语义是在新分支截断所选消息及后续，原分支仍保留全部剧情。
- 版本、分支及当前选择均落盘。刷新/重新打开读取已选分支，无自动请求。
- 生成前验证检查点可写；每次收到的增量保存至独占 IF 检查点 KV，并实时显示。Stop/无结束标记/异常断流保留非空部分回复并标记未完成；零内容不改历史。
- 完整回复写入事务失败时，不更新界面内存中的历史；屏幕保留收到的文本，独立检查点支持无需 API 的恢复。恢复沿用原 saveId（Re-roll 恢复沿用其明确分支语义）。revision 冲突拒绝覆盖其他窗口已保存的历史；可复制检查点文本处理，不自动覆盖或发请求。
- 原子事务提交后若仅检查点清理失败，仍返回已落盘的新历史并提示，不将成功保存伪装成历史写入失败。
- 仍使用 AiPhoneKvDB v1 / entries，schema、版本及已有 key 未改变；新增 ai_phone_if_pending_<requestId> 独立键。原角色卡只读、现代聊天/记忆未导入 Prompt，未写回其他模块。

## 协议

IF 专属 ifStreamEndpoint 使用实际 baseUrl 路径/官方主机及未覆盖 URL 时的 provider 默认协议，不读取模型名称来决定协议。

OpenAI 兼容 /v1 或 /chat/completions 中转允许 Claude/Gemini 等任意模型名。原生 Anthropic /messages、Google /v1beta、官方原生主机及其默认配置请求前拒绝。原生协议尚未实现，不会自动转换或重试。无法从任意自定义主机的通用 /v1 路径推断私有协议；配置此类地址应由用户确保提供 OpenAI chat/completions 协议，失败不会额外请求。

## 限制与人工验收

- 模拟 IndexedDB 不等于真实落盘耐久性证明。系统在尚未完成任何持久化写入时强杀页面，或者存储持续完全不可写，无法保证最后一段未落盘文本跨刷新保留；会报错、保留旧历史及屏幕文本供复制，绝不靠重请求补全。
- 恢复检查点过期时拒绝覆盖，不会自动合并并发历史。空检查点仅供确认未收到回复，可主动移除。
- 完整历史和世界原文保留，较大数据的单次检查点写入开销及长历史移动端性能需实机检查；不做静默压缩。
- 规则通过 Prompt 约束，不能保证模型绝不代操；未调用真实模型验证其行为。
- 备份全往返、专属记忆编辑和更完整异常恢复属于阶段 C；不得把本报告扩展为 C 完成。
